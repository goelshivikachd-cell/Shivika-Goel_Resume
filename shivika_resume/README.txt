PROFESSIONAL RESUME WEBSITE — SEPARATE HTML AND CSS

FILES:
- index.html: Website content and page structure.
- style.css: All styling, including colors, fonts, layout, navigation, cards and responsive design.
- README.txt: Setup instructions.

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the extracted professional_resume folder in Visual Studio Code.
3. Keep index.html and style.css together in the same folder.
4. Right-click index.html and select Open with Live Server.
5. The website loads its styling from style.css automatically.

HOW TO EDIT:
- Update text and sections in index.html.
- Update colors, fonts, spacing and layout in style.css.
- Add the profile photo to this folder and name it profile.jpg.
- Save and refresh the browser.

IMPORTANT:
Do not rename style.css unless you also update the stylesheet link in index.html.

PUBLISH:
Upload the complete extracted folder (including index.html and style.css, plus profile.jpg if added) to https://app.netlify.com/drop.
